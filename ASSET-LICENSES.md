# Bundled asset notices

The established Yhtua application icon and its generated platform variants have been restored verbatim from repository history predating version 2.8.0. The source filename, `lock-svgrepo-com-1024.png`, records SVG Repo as its origin, but the original asset page identifier and per-asset license were not recorded when it was added.

The icon must not be represented as an original project-owned mark or relicensed under the repository's MIT license without first confirming its upstream license. Application code remains MIT-licensed independently of that asset.

Third-party software license metadata is checked by `cargo deny`; release SBOMs provide the dependency inventory. JavaScript package license metadata should also be reviewed when dependencies change.
