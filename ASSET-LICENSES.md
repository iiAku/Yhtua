# Bundled asset notices

The Yhtua application icon and derived platform icon files are distributed with this project under the repository's MIT license by the project author.

The Yhtua mark is the original project-owned vector in `src-tauri/icons/icon-source.svg`, distributed under the repository's MIT license. Tauri generates the platform PNG, ICO, and ICNS variants from that source. The 2.8.0 release removed the former icon set because its exact upstream source and license had not been recorded.

Third-party software license metadata is checked by `cargo deny`; release SBOMs provide the dependency inventory. JavaScript package license metadata should also be reviewed when dependencies change.
